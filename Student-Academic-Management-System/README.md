# Student Record and Academic Management System

## Project Description

This project is a console-based Student Record and Academic Management System developed using Python.

The system allows users to:

- Add student information
- Display student records
- Search students using roll number
- Calculate average marks
- Calculate student grades
- Store attendance information
- Exit the application

## Technologies Used

- Python
- VS Code
- GitHub

## Concepts Used

- Variables
- Data Types
- Input and Output
- Conditional Statements
- Loops
- Functions
- Lists
- Dictionaries

Run the following command:

python student_management.py
